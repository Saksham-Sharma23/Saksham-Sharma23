### Apps & backend

| Project | What it does | Stack |
|---|---|---|
| [**StackRead**](https://github.com/Saksham-Sharma23/StackRead) | A desktop reader that groups related files into rows you swipe between. Reads PDF, EPUB, DOCX, XLSX, comics and more, and streams huge PDFs so they open instantly | Electron, TypeScript |
